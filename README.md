# CSS Grid Exercise

This project demonstrates the usage of **CSS Grid Layout** to create a responsive grid with images and text elements. The layout is designed using grid areas, and the project is hosted live on **GitHub Pages**.

## Live Demo
You can view the live project here: https://carlotaml21.github.io/GridExercise/

---

## Project Overview

This project uses **HTML** and **CSS** to create a responsive grid-based layout that includes multiple images and a centered title text. It demonstrates how CSS Grid can be used to create complex layouts with ease. The project is built with accessibility in mind, featuring descriptive alt text for all images.

---

## Project Structure

- **HTML**: Provides the basic structure and content of the page.
- **CSS**: Styles the page and defines the grid layout, including image resizing, spacing, and alignment.
- **Assets**: The images used in the project are stored in the `assets/images/` folder.

### File Breakdown

1. **index.html**:
   - Contains the grid container and child elements with their respective classes.
   - The text "Care Bears" is centrally aligned within the grid.

2. **styles.css**:
   - Defines the grid structure with `grid-template-columns`, `grid-template-rows`, and custom area assignments for each element.
   - Implements responsive design with `object-fit: cover` to ensure images fill their grid areas properly.
